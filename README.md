# سایت شخصی و رزومه

سایت شخصی یک عضو هیئت علمی و معاون دانشجویی و فرهنگی دانشگاه، ساخته‌شده با Next.js 16 (App Router)، React 19 و Tailwind CSS 4. سایت کاملاً راست‌چین (RTL) و فارسی است و با فونت وزیرمتن رندر می‌شود.

## اجرا

```bash
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را باز کنید.

## ویرایش محتوا

تمام متن‌های سایت — نام، عنوان‌ها، تحصیلات، سوابق اجرایی، دروس، مقالات، فعالیت‌ها و اطلاعات تماس — در فایل `lib/site.ts` قرار دارند. برای به‌روزرسانی رزومه فقط همین فایل را ویرایش کنید؛ نیازی به تغییر کد صفحات نیست.

محتوای فعلی نمونه است و باید با اطلاعات واقعی جایگزین شود.

## صفحات

| مسیر | محتوا |
| --- | --- |
| `/` | معرفی، آمار کلی، خلاصه پژوهش‌ها و فعالیت‌ها |
| `/resume` | تحصیلات، سوابق اجرایی و علمی، دروس تدریس‌شده |
| `/publications` | مقالات، کتاب‌ها و زمینه‌های پژوهشی |
| `/activities` | برنامه‌ها و طرح‌های دانشجویی و فرهنگی |
| `/contact` | ایمیل، دفتر، ساعات ملاقات و پیوندها |

## ساخت نسخه تولیدی

```bash
npm run build
npm start
```

`npm start` از `server.js` استفاده می‌کند تا روی هاست‌های مبتنی بر Passenger/cPanel هم قابل اجرا باشد.
