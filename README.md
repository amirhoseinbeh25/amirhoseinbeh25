# Kemkan — سایت شرکت رنگ و رزین

سایت شرکتی Kemkan (کم‌کان)، ساخته‌شده با Next.js (App Router)، Tailwind CSS و SQLite، به زبان فارسی و راست‌به‌چپ.

ساختار سایت با الهام از فیلدهای موجود در سایت‌های تامین‌کننده مواد اولیه شیمیایی (محصولات دسته‌بندی‌شده،
صفحه هر محصول، کاتالوگ، فرم استعلام قیمت، تماس با ما، بلاگ، استخدام) طراحی شده، با هویت بصری مستقل و
متمایز، متناسب با یک برند رنگ و رزین صنعتی.

## اجرا

```bash
npm install
cp .env.example .env.local   # نام کاربری/رمز پنل ادمین را عوض کن
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## پنل مدیریت (ادمین)

آدرس `/admin` یک پنل مدیریت محتوا با ورود با نام کاربری/رمز عبور است (مقادیر پیش‌فرض در `.env.example`،
حتماً قبل از انتشار عوض شود). از این پنل می‌توان محصولات، دسته‌بندی‌ها، برندها، مقالات بلاگ و اطلاعات
تماس/شرکت را بدون نیاز به ویرایش کد مدیریت کرد؛ تغییرات بلافاصله در سایت اصلی نمایش داده می‌شوند.

داده‌ها در یک پایگاه‌داده SQLite (فایل `data/kemkan.db`، در گیت commit نمی‌شود) نگه‌داری می‌شوند و در
اولین اجرا با محتوای نمونه پر می‌شوند. برای دیپلوی روی هاست serverless (مثل Vercel) توجه کن که فایل SQLite
پایدار نمی‌ماند؛ برای آن حالت بهتر است یک هاست با دیسک پایدار (VPS) استفاده شود یا بعداً به یک دیتابیس
ابری (مثل Turso/Postgres) مهاجرت شود.

## صفحات عمومی

خانه، درباره ما، محصولات (با فیلتر دسته‌بندی)، صفحه هر محصول، کاتالوگ‌ها، درخواست استعلام، تماس با ما،
بلاگ، استخدام.
