# Kemkan — سایت شرکت رنگ و رزین

سایت شرکتی Kemkan (کم‌کان)، ساخته‌شده با Next.js (App Router) و Tailwind CSS، به زبان فارسی و راست‌به‌چپ.

ساختار سایت با الهام از فیلدهای موجود در سایت‌های تامین‌کننده مواد اولیه شیمیایی (محصولات دسته‌بندی‌شده،
صفحه هر محصول، کاتالوگ، فرم استعلام قیمت، تماس با ما، بلاگ، استخدام) طراحی شده، با هویت بصری مستقل و
متمایز، متناسب با یک برند رنگ و رزین صنعتی.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را باز کنید.

## ساختار محتوا

اطلاعات قابل ویرایش شرکت (نام، آدرس، تلفن، ایمیل، شبکه‌های اجتماعی، محصولات، برندهای همکار و مقالات بلاگ)
در فایل‌های زیر نگه‌داری می‌شود و به‌راحتی قابل جایگزینی با اطلاعات واقعی است:

- `src/data/site.ts` — اطلاعات کلی و تماس شرکت
- `src/data/products.ts` — دسته‌بندی‌ها و محصولات
- `src/data/brands.ts` — برندهای همکار/تامین‌کننده
- `src/data/blog.ts` — مقالات بلاگ

## صفحات

خانه، درباره ما، محصولات (با فیلتر دسته‌بندی)، صفحه هر محصول، کاتالوگ‌ها، درخواست استعلام، تماس با ما،
بلاگ، استخدام.
