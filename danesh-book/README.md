# دانش بوک (Danesh Book)

فروشگاه اینترنتی کتاب، با ساختار و چیدمانی مشابه فروشگاه‌های ایرانی آنلاین (مانند نارون و کاموا آلیز): هدر با نوار اطلاعات و جست‌وجو، منوی دسته‌بندی، اسلایدر تبلیغاتی، بخش‌های پرفروش‌ترین‌ها / پیشنهاد لحظه‌ای / تازه‌های نشر، صفحه فروشگاه با فیلتر و مرتب‌سازی، صفحه جزئیات محصول و سبد خرید.

یک سایت کاملاً استاتیک (بدون نیاز به سرور یا بیلد) با HTML/CSS/JS ساده.

## اجرا

```bash
cd danesh-book
python3 -m http.server 8000
# سپس مرورگر را باز کنید: http://localhost:8000
```

یا به‌سادگی فایل `index.html` را مستقیماً در مرورگر باز کنید.

## ساختار پروژه

- `index.html` — صفحه اصلی (اسلایدر، دسته‌بندی‌ها، پرفروش‌ترین‌ها، پیشنهاد لحظه‌ای، تازه‌های نشر)
- `shop.html` — فروشگاه با فیلتر دسته‌بندی/قیمت و مرتب‌سازی
- `product.html?id=` — صفحه جزئیات کتاب
- `cart.html` — سبد خرید (ذخیره‌سازی در localStorage)
- `about.html`, `contact.html` — صفحات ایستا
- `css/style.css` — استایل کامل سایت (راست‌چین، واکنش‌گرا)
- `js/data.js` — داده نمونه کتاب‌ها و دسته‌بندی‌ها
- `js/layout.js` — هدر و فوتر مشترک تمام صفحات
- `js/app.js` — منطق سبد خرید، رندر کارت محصول، اسلایدر، شمارش معکوس

## افزودن کتاب جدید

یک آبجکت جدید به آرایه `BOOKS` در فایل `js/data.js` اضافه کنید؛ جلد کتاب به‌صورت خودکار و بدون نیاز به تصویر خارجی تولید می‌شود.
