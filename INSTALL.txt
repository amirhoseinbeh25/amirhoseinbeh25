نصب سایت روی cPanel — بدون ترمینال، بدون نصب، بدون build
=========================================================

این بسته از قبل ساخته شده. روی هاست نه «Run NPM Install» لازم است
نه «Run JS script». فقط آپلود و یک Restart.


مرحله ۱ — پاک کردن نصب قبلی
----------------------------
اگر قبلاً فایل‌ها را آپلود کرده‌اید، در File Manager محتویات پوشه
Application root را پاک کنید تا از نصب ناقص چیزی باقی نماند.
(اگر پوشه data دارید و محتوایی در پنل وارد کرده‌اید، اول از آن نسخه
پشتیبان بگیرید.)


مرحله ۲ — آپلود
----------------
فایل zip را داخل همان پوشه آپلود کنید، راست‌کلیک → Extract.

فایل‌ها باید مستقیم در ریشه پوشه باشند؛ یعنی server.js و node_modules
باید همان‌جا دیده شوند، نه داخل یک پوشه اضافه.


مرحله ۳ — Restart
------------------
به صفحه Setup Node.js App بروید و RESTART بزنید.

همین. سرور موقع بالا آمدن خودش پایگاه داده و کلید امنیتی را می‌سازد.


مرحله ۴ — ساخت حساب مدیر
--------------------------
در مرورگر بروید به:   نشانی-سایت/admin

صفحه «راه‌اندازی سایت» باز می‌شود. نام، ایمیل و رمز عبور (دست‌کم ۱۰
نویسه) را وارد کنید و وارد پنل می‌شوید. این صفحه بعد از آن بسته می‌شود.


تمام است.
=========

پنل:  نشانی-سایت/admin

  • آمار بازدید — کشور، شهر، دستگاه، مرورگر و IP
  • محتوای سایت — از ویدئوی پس‌زمینه تا تک‌تک ردیف‌های رزومه
  • فایل‌ها — بارگذاری عکس و ویدئو


اگر مشکلی پیش آمد
==================

«خطای ۵۰۰ یا صفحه سفید»
  در صفحه Node.js یک‌بار RESTART بزنید و لاگ خطا را همان‌جا ببینید.

«فرم‌های پنل کار نمی‌کنند و پیام Invalid Server Actions request می‌دهد»
  یعنی سایت پشت کلادفلر یا پراکسی است. در صفحه Node.js بخش
  Environment variables اضافه کنید:
      نام:   ALLOWED_ORIGINS
      مقدار: arashrahmani.ir
  بعد Restart.

«ستون کشور و شهر در آمار خالی است»
  کشور و شهر خودکار پر می‌شود و تنظیمی نمی‌خواهد. اگر بعد از چند بازدید
  واقعی هم خالی ماند، یعنی هاست اجازه درخواست به بیرون نمی‌دهد؛ از
  پشتیبانی هاست بخواهید دسترسی به ipwho.is را باز کند.

  اگر نمی‌خواهید IP بازدیدکننده‌ها به سرویس بیرونی برود، در بخش متغیرها:
      نام:   GEO_API_URL
      مقدار: off
  بعد Restart. آن‌وقت کشور و شهر ثبت نمی‌شود و بقیه آمار سر جایش می‌ماند.


پشتیبان‌گیری
=============

فقط دو پوشه:

  data            ← پایگاه داده (تمام محتوا و آمار)
  public/uploads  ← عکس‌ها و ویدئوهای بارگذاری‌شده

با File Manager هر از چندی این دو را دانلود کنید.


به‌روزرسانی سایت در آینده
==========================

بسته تازه را بگیرید و همه فایل‌ها را جایگزین کنید، جز پوشه‌های data و
public/uploads که محتوای شما در آن‌هاست. بعد Restart.
