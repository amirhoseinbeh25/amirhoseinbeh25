نصب سایت روی cPanel — بدون نیاز به ترمینال
===========================================

مرحله ۱ — آپلود فایل‌ها
------------------------
در cPanel وارد File Manager شوید و به پوشه‌ای بروید که در تنظیمات
Node.js به‌عنوان Application root گذاشته‌اید (مثلاً arashrahmani.ir).

فایل zip را همان‌جا آپلود کنید، روی آن راست‌کلیک و Extract بزنید.

دقت کنید فایل‌ها مستقیم داخل همان پوشه باشند، نه داخل یک پوشه اضافه.
یعنی server.js و package.json باید در ریشه همان پوشه دیده شوند.


مرحله ۲ — نصب بسته‌ها
----------------------
به صفحه Setup Node.js App برگردید و دکمه «Run NPM Install» را بزنید.

چند دقیقه طول می‌کشد. این کار بسته‌ها را نصب می‌کند و به‌طور خودکار
کلاینت پایگاه داده را هم می‌سازد.


مرحله ۳ — ساخت نسخه اجرایی
---------------------------
دکمه «Run JS script» را بزنید و از فهرست، گزینه build را انتخاب کنید.

این طولانی‌ترین مرحله است (چند دقیقه).


مرحله ۴ — راه‌اندازی مجدد
--------------------------
دکمه RESTART بالای همان صفحه را بزنید.

سرور موقع بالا آمدن، خودش پایگاه داده و کلید امنیتی را می‌سازد.
هیچ کاری لازم نیست بکنید.


مرحله ۵ — ساخت حساب مدیر
-------------------------
در مرورگر بروید به:   نشانی-سایت/admin

چون اولین بار است، صفحه «راه‌اندازی سایت» باز می‌شود. نام، ایمیل و رمز
عبور (دست‌کم ۱۰ نویسه) را وارد کنید. همان لحظه وارد پنل می‌شوید.

این صفحه بعد از ساخت حساب بسته می‌شود و دیگر باز نمی‌شود.


تمام است.
=========

از این به بعد همه‌چیز از پنل انجام می‌شود:

  نشانی-سایت/admin

  • آمار بازدید — کشور، شهر، دستگاه، مرورگر و IP
  • محتوای سایت — از ویدئوی پس‌زمینه تا تک‌تک ردیف‌های رزومه
  • فایل‌ها — بارگذاری عکس و ویدئو


اگر مشکلی پیش آمد
==================

«صفحه سفید است یا خطای ۵۰۰»
  در صفحه Node.js دکمه RESTART را بزنید. اگر باز هم بود، لاگ خطا را در
  همان صفحه ببینید.

«فرم‌های پنل کار نمی‌کنند و پیام Invalid Server Actions request می‌دهد»
  یعنی سایت پشت کلادفلر یا پراکسی است. در صفحه Node.js بخش
  Environment variables یک متغیر اضافه کنید:
      نام:   ALLOWED_ORIGINS
      مقدار: arashrahmani.ir
  بعد Restart بزنید.

«ستون کشور و شهر در آمار خالی است»
  اگر سایت پشت کلادفلر نیست، در همان بخش Environment variables اضافه کنید:
      نام:   GEO_API_URL
      مقدار: https://ipapi.co/{ip}/json/
  بعد Restart بزنید. بقیه آمار بدون این هم کار می‌کند.


پشتیبان‌گیری
=============

فقط دو پوشه مهم‌اند:

  data            ← پایگاه داده (تمام محتوا و آمار)
  public/uploads  ← عکس‌ها و ویدئوهای بارگذاری‌شده

هر از چندی با File Manager این دو را دانلود کنید. همین کافی است.
